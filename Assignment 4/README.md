## Compile and execute

From `Assignment 4` in PowerShell:

```powershell
foreach ($task in 1..6) {
  $folder = "Task{0:D2}" -f $task
  New-Item -ItemType Directory -Force "build/$folder" | Out-Null
  javac -d "build/$folder" (Get-ChildItem "$folder/*.java").FullName
}

java -cp build/Task01 FeePaymentApp
java -cp build/Task02 AppointmentDeskApp
java -cp build/Task03 LibrarySearchApp
java -cp build/Task04 DrawingPadApp
java -cp build/Task05 CurrencyConverterStyles
java -cp build/Task06 EventRegistrationApp
```

For MySQL Task 6, execute `Task06/schema.sql`, set `EVENT_DB_URL`, `EVENT_DB_USER`, and `EVENT_DB_PASSWORD`, then run:

```powershell
java -cp "build/Task06;path/to/mysql-connector-j.jar" EventRegistrationApp --mysql
```
